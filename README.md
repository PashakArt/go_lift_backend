# 🏋️‍♂️ GoLift Backend

Монорепозиторий бэкенд-сервисов приложения **GoLift** — платформы для трекинга тренировок и управления фитнес-программами (Telegram Mini App).

Архитектура построена на микросервисном подходе с взаимодействием по **gRPC** (Proto3) и мультиарендной архитектурой (Multitenancy).

---

## 🏗 Архитектура и компоненты

Репозиторий использует **Go Workspaces** (`go.work`) для удобной работы с монорепозиторием.

### Сервисы:

1. **`tg-bot-gateway`**:
   * Точка входа для Telegram Mini App и Телеграм-бота.
   * Валидация `initData` от Telegram, аутентификация и выдача JWT-токенов.
   * Выступает в роли API Gateway: проксирует запросы от клиента к gRPC-сервису `workout-service`.

2. **`workout-service`**:
   * Основной бизнес-сервис.
   * Управляет сессиями тренировок, подходами, упражнениями, программами (шаблонами) и группами мышц.
   * Изоляция данных по арендаторам (Multitenancy support).
   * Взаимодействие с PostgreSQL через чистый SQL (`/repository/queries`).

3. **`api`**:
   * Единое хранилище Proto-контрактов (`workout.proto`) и сгенерированных gRPC клиентских/серверных стабов.

---

## 🛠 Технологический стек

* **Язык:** Go (Golang)
* **Транспорт:** gRPC, Protocol Buffers v3, HTTP / REST
* **База данных:** PostgreSQL
* **Аутентификация:** JWT, Telegram `initData` HMAC Verification
* **Контейнеризация и Оркестрация:** Docker, Docker Compose
* **Кодогенерация:** `protoc`, `buf`
